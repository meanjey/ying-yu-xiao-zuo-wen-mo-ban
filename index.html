审题

动笔前先想清三件事，30 秒搞定

我们新补

审题只问 3 问

1
写给谁？ → 定抬头

不知道具体人名（客服、机构）→ Dear Sir or Madam,

2
两个任务点是什么？ → 直接抄题干动词

题干 1) 2) 列的两个动作就是全文要干的两件事，首段照抄（记得换人称：him → you，your → my）。

3
要不要回信？ → 定尾段

投诉 / 申请 / 建议 / 邀请 / 推荐 → 要回信版；告知 / 招募 / 回复问询 → 不用回信版。

写信还是通知，一句话判断：题干里有 notice 这个词 → 通知；没有 → 写信（letter 和 email 都按信写）。

审完题，开始写第一段

写信版：

固定骨架（28 词，整段照背）

尾段 2 选 1 + 落款

① 不用回信（告知 / 招募 / 回复问询）：

I would be glad if you found the information / suggestions mentioned above helpful. Should you have any further questions, please feel free to contact me.提信息用 information，建议用 suggestions；found 是虚拟语气，写 find 也不扣分用法：尾段｜告知、招募、回复问询类题｜可换：information / suggestions 按正文内容二选一

② 要回信（投诉 / 申请 / 建议 / 邀请 / 推荐）：

I would appreciate it if you could take my complaint / application / recommendation / invitation / questions into serious consideration. And I would be much obliged to you for an early and positive reply.空里按文体填一个用法：尾段｜投诉、申请、建议、邀请、推荐类题｜可换：空里按文体填一个词

落款规则：写信 → Yours truly, + 题干指定名，没指定默认 Li Ming（Yours 只有 Y 大写）；通知 → 落机构名 + 日期，不署个人名。

我们新补

尾段升级：给读者一个下一步

结尾别只写空泛的 an early and positive reply，要给读者一个具体的下一步：动作 + 期限，或一个联系点。例：请 3 月 31 日前答复；有问题去 102 室 / 问前台；3 月 10 日前交简历。通知类尤其要用——报名截止 + 找谁报名，两样都要写死。

用法：尾段（本步）｜通知类必用，邀请、申请、招募类也用｜把「动作 + 截止时间 / 联系人 / 地点」写成一句具体的收尾，接在模板尾段句之后或替换空泛的 reply 句。

我们新补

口气按关系分

写给陌生人 / 教授 / 客服（正式）：多用 could、would，而且不用缩写——cannot、do not 写全，I would 不写 I'd。

写给朋友（随意）：可以缩写（can't、don't、I've 都行），落款可换 Best wishes,。

用法：全程（首段到落款）｜看审题第 1 问定的关系：陌生人、教授、客服走正式；朋友走随意。

通读一遍问自己：读者读完还要回头问我什么吗？还要问 = 漏了细节——时间 / 地点 / 找谁 / 截止，缺哪个补哪个。

易错清单 · 完整版（全站只此一份）

  • suggestions 加 s，information 不加 s——建议不止一条所以可数；information 不可数，永远单数。
  • 抬头每个词首字母大写 + 逗号：Dear International Student Volunteer, 别只大写第一个词。
  • 落款 Yours 只有 Y 大写：Yours truly, 后跟逗号；署名默认 Li Ming。
  • 过渡词后首字母小写：First of all, it… 不要写成 First of all, It…
  • 过渡词不许自创：别把 In addition 换成 last but not least，三点不分主次。
  • 照抄题干要换人称：him → you，your → my，原样抄 = 没审题。
  • Main Building 两个词都大写；放不进主楼用 behind / beside the Main Building。
  • 专有名词别半截大写：该大的全大；句中普通词（consideration 等）再重要也不大写。
  • attachment 纸质信也能用：附件可以是照片、名单、资料。
  • Regarding 后必须跟名词，别写成光秃秃的 Regarding, there are…
  • 通知别写 Dear 和 Yours truly：标题 Notice 居中，结尾右下角写单位 + 日期。

模板细则

首段：次要目的只有感谢 / 道歉 / 祝贺这类纯情感目的，题干没有就跳过。主要目的四选一都不贴时照抄题干，必须换人称（him → you，your → my）。

主体：Regarding 后面必须接名词，别写成光秃秃的 Regarding, there are…；Main Building 两个词都大写，放不进主楼用 behind / beside the Main Building。

附件句：任何文体都能写，附件可以是照片、名单、资料。

词数：全文约 100 词，固定骨架约占 50+ 词，真正要填的只有主体段 3 个论点。得分核心是切题，不是辞藻。

杂糅题规律：同一道题跨了两元就是杂糅题。不慌——三坑按需跨元混填即可，这正是三分归元法比「按类型背模板」强的地方。范文里引用的句子都是片段，原句看这里：
